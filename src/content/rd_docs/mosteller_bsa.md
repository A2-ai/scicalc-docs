## Alias

mosteller_bsa

## Description

Calculates Body Surface Area based on Weight and Height using Mosteller equation

## Usage

```r
mosteller_bsa(
  weight,
  height
)
```

## Arguments

| Name | Description |
|------|-------------|
| `weight` | weight of subject (kg) |
| `height` | height of subject (cm) |

## Returns

the body surface area (m^2)

## Examples

```r
mosteller_bsa(70, 170)
```
