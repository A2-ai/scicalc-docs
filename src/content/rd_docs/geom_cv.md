## Description


 Computes the geometric CV of a vector x

## Usage

```r

 geom_cv(x, na.rm = FALSE)

```
## Arguments

| Name   | Description |
|--------|-------------|
|`x`| vector of data you want the geometric CV of.|
|`na.rm`| boolean to remove NA from vector. Default is FALSE|
## Returns


 the geometric CV of the input vector x

## Examples

```r

 geom_cv(c(1, 2, 3, 2, 1))

```
