## Description

Takes character input and returns TRUE/FALSE if other/explicit race

## Usage

```r
is_other(x)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | input character representing race |

## Value

boolean representing Race == Other

## Examples

```r
is_other("OTHER")

is_other("BLACK")
```
