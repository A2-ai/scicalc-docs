Reading in an excel file gives the data hash as well as the sheet names within the file
```r
> d <- read_file_with_hash(here::here("inst/extdata/data/source/test_excel.xlsx"))
test_excel.xlsx: f665dce4222df738750216bb9cd53819
Sheets in test_excel.xlsx: model_summary, sheet with space, empty
```
The default is to read the first sheet, but supplying sheet argument (either numeric or sheet name) allows you to read any sheet within the file
