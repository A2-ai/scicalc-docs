## Description

Convert Bilirubin Concentration Units

## Usage

```r
convert_bili(bili)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `bili` | bilirubin concentration (µmol/L) |

## Value

Bilirubin concentration (mg/dL)

## Examples

```r
convert_bili(17.1) # ≈ 1 mg/dL

df <- data.frame(
  ID = c(1, 2, 3, 4),
  BILI = c(10, 15, 25, 40)
)

df <- df %>%
  dplyr::group_by(ID) %>%
  dplyr::mutate(BILIBL = convert_bili(BILI))
df
```
