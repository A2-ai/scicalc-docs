## Description

Convert absolute eGFR to relative eGFR

## Usage

```r
convert_abs_to_rel(est, bsa)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `est` | Absolute eGFR (mL/min) |
| `bsa` | Body surface area (m²) |

## Value

Relative eGFR (mL/min/1.73m²)
