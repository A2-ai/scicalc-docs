## Description

Convert absolute eGFR to relative eGFR






## Usage

```r
convert_abs_to_rel(est, bsa)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>est</code></td>
<td>Absolute eGFR (mL/min)</td>
</tr>
<tr>
<td><code>bsa</code></td>
<td>Body surface area (m²)</td>
</tr>
</tbody>
</table>
</div>


## Value

Relative eGFR (mL/min/1.73m²)
