## Description

Check if Ethnicity is Not Hispanic or Latino

## Usage

```r
is_not_hispanic_or_latino(x)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | input character representing ethnicity |

## Value

boolean representing Ethnic == "Not Hispanic or Latino"
