## Description

Takes character input and returns TRUE/FALSE if white/other

## Usage

```r
is_white(x)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | input character representing race |

## Value

boolean representing Race == White

## Examples

```r
is_white("WHITE")

is_white("BLACK")
```
