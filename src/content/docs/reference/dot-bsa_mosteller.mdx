## Description

The equation used by [`bsa()`](../bsa/) with `method = "Mosteller"`.

## Details

The Mosteller equation for BSA:
$$
BSA = \sqrt{\frac{W \cdot H}{3600}}
$$


where:
- $W$ = weight (kg)
- $H$ = height (cm)
