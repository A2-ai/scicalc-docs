## Description

Calculate Geometric Standard Deviation

## Details

The geometric standard deviation is calculated as:
$$
GSD = \exp\left(\sqrt{Var[\log(x)]}\right)
$$






## Usage

```r
geom_sd(x, na.rm = FALSE)
```
