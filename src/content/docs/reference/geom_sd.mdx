## Description

Computes the geometric standard deviation of a vector x.

## Usage

```r
geom_sd(x, na.rm = FALSE)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | The vector of data you want the geometric sd of. |
| `na.rm` | a boolean to remove NA values. Default is False |

## Value

the geometric standard deviation of x

## Examples

```r
geom_sd(c(1, 2, 3, 2, 1))
```
