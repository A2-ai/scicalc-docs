## Description

Write Data File with Hash Output






## Usage

```r
write_file_with_hash(
  data,
  path,
  overwrite = FALSE,
  ...,
  algo = "blake3",
  writer = NULL,
  force = FALSE
)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>

<tr>
<td><code>data</code></td>
<td>the data object to write to file</td>
</tr>
<tr>
<td><code>path</code></td>
<td>the destination of the file (csv or parquet)</td>
</tr>

<td><code>overwrite</code></td>

</tr>
<tr>
<td><code>...</code></td>
<td>additional arguments for digest, write_csv, write_parquet, or `writer`.</td>
</tr>
<tr>
<td><code>algo</code></td>
<td>hashing algorithm to use, default is "blake3"</td>
</tr>
<tr>
<td><code>writer</code></td>
<td>optional function used to write the file, called as `writer(data, path, ...)`. Required for file extensions this function doesn't know how to write. For a known extension (csv, parquet), `writer` is ignored unless `force = TRUE`.</td>
</tr>
<tr>
<td><code>force</code></td>
<td>if `TRUE`, use `writer` even for a known extension instead of the built-in writer. Must be `FALSE` (the default) when `writer` is not supplied.</td>
</tr>
</tbody>
</table>
</div>


## Value

Nothing, File is created and hash of created file is printed



## Examples

```r
# Not run:
df <- data.frame(
  "a" = c(1, 2, 3, 4)
  "b" = c("A", "B", "C", "D")
)
write_file_with_hash(df, "data.csv")
write_file_with_hash(df, "data.rds", writer = saveRDS)
```
