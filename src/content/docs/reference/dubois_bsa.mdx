This function is deprecated; use [`bsa()`](../bsa/) with `method = "Dubois"`.

## Details

The Du Bois equation for BSA:
$$
BSA = 0.007184 \cdot W^{0.425} \cdot H^{0.725}
$$


where:
- $W$ = weight (kg)
- $H$ = height (cm)






## Usage

```r
dubois_bsa(weight, height)
```
