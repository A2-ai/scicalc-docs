## Description

Check for Unique Units per Parameter






## Usage

```r
check_for_unique_units(params, units)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>params</code></td>
<td>a column from a dataset with lab parameters</td>
</tr>
<tr>
<td><code>units</code></td>
<td>a column from a dataset with units associated with those parameters</td>
</tr>
</tbody>
</table>
</div>


## Value

a boolean



## Examples

```r
df <- data.frame(
  PARAM = c(
    "ALB","ALT","AST","CR","TBIL",
    "ALB","CR","TBIL","ALT","AST"),
  UNIT = c(
    "g/L","U/L","U/L","umol/L","umol/L",
    "U/L","μmol/L","μmol/L","IU/L","IU/L")
)
check_for_unique_units(df$PARAM, df$UNIT)
```
### Output

```
[1] FALSE
```
