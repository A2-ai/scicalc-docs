## Description

Check for Unique Units per Parameter

## Usage

```r
check_for_unique_units(params, units)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `params` | a column from a dataset with lab parameters |
| `units` | a column from a dataset with units associated with those parameters |

## Value

a boolean

## See Also

Other unit_checking: 
<a href={`${import.meta.env.BASE_URL}reference/get_unique_units_df`}><code>get_unique_units_df</code></a>

## Examples

```r
df <- data.frame(
  PARAM = c(
    "ALB","ALT","AST","CR","TBIL",
    "ALB","CR","TBIL","ALT","AST"),
  UNIT = c(
    "g/L","U/L","U/L","umol/L","umol/L",
    "U/L","μmol/L","μmol/L","IU/L","IU/L")
)
check_for_unique_units(df$PARAM, df$UNIT)
```
