## Description

Takes character input and returns TRUE/FALSE if asian/other

## Usage

```r
is_asian(x)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | input character representing race |

## Value

boolean representing Race == Asian

## Examples

```r
is_asian("ASIAN")

is_asian("BLACK")
```
