## Description

[![[Deprecated]](/figures/lifecycle-deprecated.svg)](https://lifecycle.r-lib.org/articles/stages.html#deprecated)

This function is deprecated; use [`bsa()`](../bsa/) with `method = "Mosteller"`.

## Details

The Mosteller equation for BSA:
$$
BSA = \sqrt{\frac{W \cdot H}{3600}}
$$


where:
- $W$ = weight (kg)
- $H$ = height (cm)






## Usage

```r
mosteller_bsa(weight, height)
```
