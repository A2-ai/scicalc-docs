## Description

Categorize Continuous Variable into Quantile Bins






## Usage

```r
categorize(continuous_var, nbins = 4, units = "", type = 7, digits = 1)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>continuous_var</code></td>
<td>continuous variable data</td>
</tr>
<tr>
<td><code>nbins</code></td>
<td>number of bins to break data into, default is 4</td>
</tr>
<tr>
<td><code>units</code></td>
<td>string, optional units string to add to labels of categorized data</td>
</tr>
<tr>
<td><code>type</code></td>
<td>type argument for stats::quantile, default is 7</td>
</tr>
<tr>
<td><code>digits</code></td>
<td>number of digits to round quantile breaks to for labels, default is 1</td>
</tr>
</tbody>
</table>
</div>


## Value

a vector of categorized data as factor



## Examples

```r
x <- rnorm(1000, mean = 10, sd = 5)
categorize(x, nbins = 5)
```
