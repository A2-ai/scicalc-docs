## Description

The equation used by [`egfr()`](../egfr/) with `method = "Schwartz"`.

## Details

The Schwartz equation for pediatric eGFR:
$$
eGFR = 0.413 \cdot \frac{H}{S_{cr}}
$$


where:
- $H$ = height (cm)
- $S_{cr}$ = serum creatinine (mg/dL)
