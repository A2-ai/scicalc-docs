## Description

Takes character input and returns TRUE/FALSE if female/male

## Usage

```r
is_female(x)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | input character representing female or male |

## Value

boolean representing female

## Examples

```r
is_female("F")

is_female(c("MALE", "FEMALE"))
```
