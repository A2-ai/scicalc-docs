## Description

Get Unique Parameter-Unit Combinations

## Usage

```r
get_unique_units_df(params, units)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `params` | a column from a dataset with lab parameters |
| `units` | a column from a dataset with units associated with those parameters |

## Value

a dataframe with distinct units and parameters with IU replaced to U and mu replaced with u

## See Also

Other unit_checking: 
<a href={`${import.meta.env.BASE_URL}reference/check_for_unique_units`}><code>check_for_unique_units</code></a>

## Examples

```r
df <- data.frame(
  PARAM = c(
    "ALB","ALT","AST","CR","TBIL",
    "ALB","CR","TBIL","ALT","AST"),
  UNIT = c(
    "g/L","U/L","U/L","umol/L","umol/L",
    "U/L","μmol/L","μmol/L","IU/L","IU/L")
)
get_unique_units_df(df$PARAM, df$UNIT)
```
