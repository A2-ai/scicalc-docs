## Description

Get Unique Parameter-Unit Combinations






## Usage

```r
get_unique_units_df(params, units)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>params</code></td>
<td>a column from a dataset with lab parameters</td>
</tr>
<tr>
<td><code>units</code></td>
<td>a column from a dataset with units associated with those parameters</td>
</tr>
</tbody>
</table>
</div>


## Value

a dataframe with distinct units and parameters with IU replaced to U and mu replaced with u



## Examples

```r
df <- data.frame(
  PARAM = c(
    "ALB","ALT","AST","CR","TBIL",
    "ALB","CR","TBIL","ALT","AST"),
  UNIT = c(
    "g/L","U/L","U/L","umol/L","umol/L",
    "U/L","μmol/L","μmol/L","IU/L","IU/L")
)
get_unique_units_df(df$PARAM, df$UNIT)
```
### Output

```
  PARAM   UNIT
1   ALB    g/L
2   ALT    U/L
3   AST    U/L
4    CR umol/L
5  TBIL umol/L
6   ALB    U/L
```
