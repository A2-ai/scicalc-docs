This function takes character input and returns TRUE/FALSE if not hispanic/other

## Arguments
* `x`: character representing ethnicity

## Returns 
* `TRUE` if `tolower(x)` is `"not hispanic"`
* `TRUE` if `tolower(x)` is `"not latino"`
* `TRUE` if `tolower(x)` is `"not hispanic or latino"`
* `FALSE` otherwise
