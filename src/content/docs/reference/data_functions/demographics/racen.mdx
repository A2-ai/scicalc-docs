Takes character input representing race, and returns standard yspec numeric value for Race

## Arguments
* `racec`: character representing race

## Returns
- `1` if `racec = "WHITE"`
- `2` if `racec = "BLACK"`
- `3` if `racec = "ASIAN"`
- `4` if `racec = "OTHER"`
- `-999` if `ethinicc = "UNKNOWN"`
