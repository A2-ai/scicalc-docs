This function takes character input and returns TRUE/FALSE if hispanic/other

## Arguments
* `x`: character representing ethnicity

## Returns 
* `TRUE` if `tolower(x)` is `"hispanic"`
* `TRUE` if `tolower(x)` is `"latino"`
* `TRUE` if `tolower(x)` is `"hispanic or latino"`
* `FALSE` otherwise
