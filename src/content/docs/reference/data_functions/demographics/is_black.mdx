This function takes character input and returns TRUE/FALSE if black/other

## Arguments
* `x`: character representing race

## Returns 
* `TRUE` if `tolower(x)` is `"black"`
* `TRUE` if `tolower(x)` is `"african american"`
* `TRUE` if `tolower(x)` is `"black or african american"`
* `FALSE` otherwise
