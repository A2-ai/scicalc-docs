Calculates hepatic function criteria

## Arguments
- `ast` - Aspartate aminotransferase (AST) concentration $\text{IU/L}$
- `ulnast` - Upper limit of normal `AST` concentration $\text{IU/L}$, typically 33
- `bili` - Bilirubin concentration $\text{mg/dL}$
- `ulnbili` - Upper limit of normal bilirubin concentration $\text{mg/dL}$, typically 1.2
