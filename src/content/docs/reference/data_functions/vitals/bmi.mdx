## Equation
Using 
- $W$ as weight
- $H$ as height

$$
BBMI = \frac{W}{(H/100)^2}
$$

## Code
```r
bbmi <- weight/((height/100)^2)
```
## Units
This gives `bbmi` in units of $\text{kg/m}^2$
