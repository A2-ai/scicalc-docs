Calculates eGFR based on the method specified

## Arguments
- `sexf` - Boolean, `TRUE` if subject is female
- `raceb` - Boolean, `TRUE` if subject is black
- `age` - Subject age $\text{year}$
- `creat` - Subject serum creatinine levels $\text{mg/dL}$
- `cystc` - Subject cystatin C levels $\text{mg/dL}$ - only used in CKDEPI 2021 CYSTATIN Method
- `height` - Subject height $\text{cm}$
- `method` - Specifies which method to use. Options are [CKDEPI 2009](/reference/data_functions/vitals/ckdepi_2009_egfr), [CKDEPI 2021](/reference/data_functions/vitals/ckdepi_2021_egfr), [MDRD](/reference/data_functions/vitals/mdrd_egfr),  [Schwartz](/reference/data_functions/vitals/schwartz_egfr)

## Equation
The equation used is dependent on `method`
- [CKDEPI 2009](/reference/data_functions/vitals/ckdepi_2009_egfr#equation)
- [CKDEPI 2021](/reference/data_functions/vitals/ckdepi_2021_egfr#equation)
- [CKDEPI 2021 CYSTATIN](/reference/data_functions/vitals/ckdepi_2021_egfr_cystatin#equation)
- [MDRD](/reference/data_functions/vitals/mdrd_egfr#equation)
- [Schwartz](/reference/data_functions/vitals/schwartz_egf#equation)
