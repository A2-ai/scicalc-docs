## Equation
Using:
- $S_{cr}$ for serum creatinine levels
- $ \kappa = \begin{cases} 0.7 & \text{if sexf is True}\\ 0.9 & \text{otherwise} \end{cases}$
- $ \alpha = \begin{cases} -0.241 & \text{if } \text{sexf is true}\\-0.302 & \text{otherwise} \end{cases}$
- $A$ for age
- $ F = \begin{cases} 1 & \text{if sexf is True}\\ 0 & \text{otherwise} \end{cases}$

$$
\text{eGFR} = 142 \cdot 
    \min(S_{cr}/\kappa, 1)^\alpha \cdot
    \max(S_{cr}/\kappa, 1)^{-1.2} \cdot
    0.9938^A \cdot
    1.012^F 
$$

## Code
```r
K <- dplyr::if_else(sexf, 0.7, 0.9)
alpha <- dplyr::if_else(sexf, -0.241, -0.302)
sex_mult <- dplyr::if_else(sexf, 1.012, 1)

ratio <- creat/K
scr_k_min <- dplyr::if_else(ratio < 1, ratio^alpha, 1)
scr_k_max <- dplyr::if_else(ratio > 1, ratio^-1.200, 1)

egfr <- 142 *
    scr_k_min *
    scr_k_max *
    (0.9938^age) *
    sex_mult
```
## Units
This gives $\text{eGFR}$ in units of $\frac{\text{mL}}{\text{min} \cdot 1.73\text{m}^2}$
