## Equation

Using 
- $A$ for age
- $W$ for Weight
- $S_{cr}$ for serum Creatinine levels
- $F = \begin{cases} 0.85 & \text{if female}, \\ 1 & \text{otherwise}\end{cases}$
$$
\text{crcl} = F \cdot \frac{(140 - \text{A}) W}{72 S_{cr}}
$$ 

## Code
```r
sex_mult <- ifelse(sexf, 0.85, 1)
crcl <- (140 - age) * weight / (72 * creat) * sex_mult
```

## Units
This gives creatinine clearance in $\text{mL/min}$
