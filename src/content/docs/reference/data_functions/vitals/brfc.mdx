Calculates renal impairment categories based on CrCL

## Arguments
- `crcl` creatinine clearance rate $\text{mL/min}$

## Equation

$$
\text{brfc} = 
\begin{cases} 
    0 & \text{if crcl} \ge 90, \\
    1 & \text{if crcl} \ge 60, \\
    2 & \text{if crcl} \ge 30, \\
    3 & \text{if crcl} < 30, \\
    -999 & \text{otherwise}
\end{cases}
$$

## Code
```r
brfc <- dplyr::case_when(
    crcl >= 90 ~ 0,
    crcl >= 60 ~ 1,
    crcl >= 30 ~ 2,
    crcl <  30 ~ 3,
    .default = -999
)
```

## Units
The renal impairment categories are unitless.
