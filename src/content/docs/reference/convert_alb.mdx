## Description

Convert Albumin Concentration Units

## Usage

```r
convert_alb(alb)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `alb` | albumin concentration (g/L) |

## Value

Albumin concentration (g/dL)

## Examples

```r
convert_alb(40)

df <- data.frame(
  ID = c(1, 2, 3, 4),
  ALB = c(35, 40, 28, 45)
)

df <- df %>%
  dplyr::group_by(ID) %>%
  dplyr::mutate(ALBBL = convert_alb(ALB))
df
```
