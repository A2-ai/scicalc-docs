## Description

Convert Ethnicity to Numeric Code

## Usage

```r
ethnicn(ethnicc)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `ethnicc` | Ethnic character |

## Value

the standard yspec numeric value for the inputted Ethnic character
