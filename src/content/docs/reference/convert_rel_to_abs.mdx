## Description

Convert relative eGFR to absolute eGFR






## Usage

```r
convert_rel_to_abs(est, bsa)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>est</code></td>
<td>Relative eGFR (mL/min/1.73m²)</td>
</tr>
<tr>
<td><code>bsa</code></td>
<td>Body surface area (m²)</td>
</tr>
</tbody>
</table>
</div>


## Value

Absolute eGFR (mL/min)
