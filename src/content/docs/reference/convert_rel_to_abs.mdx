## Description

Convert relative eGFR to absolute eGFR

## Usage

```r
convert_rel_to_abs(est, bsa)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `est` | Relative eGFR (mL/min/1.73m²) |
| `bsa` | Body surface area (m²) |

## Value

Absolute eGFR (mL/min)
