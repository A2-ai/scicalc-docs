## Description

Convert Serum Creatinine Concentration Units






## Usage

```r
convert_creat(creat)
```

</tr>
</tbody>
</table>
</div>


## Value

Serum Creatinine concentration (mg/dL)



## Examples

```r
convert_creat(88.42) # ≈ 1 mg/dL

df <- data.frame(
  ID = c(1, 2, 3, 4),
  CREAT = c(70, 90, 110, 130)
)

df <- df |>
  dplyr::group_by(ID) |>
  dplyr::mutate(CREATBL = convert_creat(CREAT))
df
```
