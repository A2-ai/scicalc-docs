## Description

Computes the geometric mean of a vector.

## Usage

```r
geom_mean(x, na.rm = FALSE)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `x` | vector to compute geometric mean of |
| `na.rm` | boolean to remove NA from vector in calcualtion. Default is False |

## Value

geometric mean of input vector x

## Examples

```r
geom_mean(c(1, 2, 3, 2, 1))
```
