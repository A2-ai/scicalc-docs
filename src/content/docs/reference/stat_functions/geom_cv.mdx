## Equation
$$
\text{geometric }CV = \sqrt{
    \exp{\left(
        \text{Var} \left[ \log(x)\right]
        \right)
    } - 1
}
$$

## Code
```r
geom_cv = sqrt(exp(stats::sd(log(x), na.rm = na.rm)**2) - 1)
```
