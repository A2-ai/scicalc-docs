## Description

Calculate Body Surface Area






## Usage

```r
bsa(weight, height, method = "Dubois")
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>weight</code></td>
<td>weight of a subject (kg)</td>
</tr>
<tr>
<td><code>height</code></td>
<td>height of a subject (cm)</td>
</tr>
<tr>
<td><code>method</code></td>
<td>equation to use: [bsa(method = "Dubois")](../dot-bsa_dubois/) or [bsa(method = "Mosteller")](../dot-bsa_mosteller/).</td>
</tr>
</tbody>
</table>
</div>


## Value

bsa (m^2)



## Examples

```r
bsa(70, 170)
bsa(70, 170, method = "Mosteller")
bsa(70, 170, method = "Dubois")
```
