## Description

Also returns numeric for single character Sex characters "F" and "M"

## Usage

```r
sexf(sex)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `sex` | Sex character |

## Value

the standard yspec numeric value for the inputted Sex character
