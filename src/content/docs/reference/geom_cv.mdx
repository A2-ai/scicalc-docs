## Description

Calculate Geometric Coefficient of Variation

## Details

The geometric coefficient of variation is calculated as:
$$
GCV = \sqrt{\exp(Var[\log(x)]) - 1}
$$






## Usage

```r
geom_cv(x, na.rm = FALSE)
```

## Value

the geometric CV of the input vector x




## Examples

```r

```
